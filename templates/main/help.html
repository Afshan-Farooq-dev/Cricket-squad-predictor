About the Project

Cricket Squad Selector is an MSc Final Year Project that uses Machine Learning to help cricket teams select the best possible playing XI based on match conditions. The system analyses historical player performance data to generate optimal squads for any match scenario.

The application covers four international teams — India, England, Australia, and Pakistan — across all three formats: ODI, T20, and Test matches.

How the ML Works

XGBoost Model

Used for squad selection — identifies the best 11 players based on match conditions like pitch type, weather, and opposition strength.

Random Forest Model

Used for performance scoring — evaluates each player's current form and assigns a performance score from 0-100.

How to Use

  1. Create an account or log in.
  2. Go to Generate Squad.
  3. Select your country, opposition, format, pitch, venue and weather.
  4. Click Generate — the model picks your XI.
  5. View the full squad with batting order, bowling combo, and charts.
  6. Save your squad to your dashboard for future reference.
